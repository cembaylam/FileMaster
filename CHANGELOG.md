# Changelog

## 0.1.0 — 2026-11-02

First public release.

- Three-column yazi-style browser built on `getattrlistbulk` and FSEvents, with resizable, live-redrawing panes
- Previews: syntax highlighting (~35 languages, Fira Code), images, video/audio posters, QuickLook, hex fallback
- Built-in viewer/player: video seek/percent keys, instant borderless full screen, PDF and image zoom
- File operations in the background: yank/cut/paste, trash, permanent delete, create, rename, symlink, open with
- Find, filter, recursive name search, ripgrep content search, frecent jump, bookmarks
- Native window tabs, git status markers, `keymap.toml` overrides, which-key popup, Settings window
- Ad-hoc signed DMG (`make dist`)
